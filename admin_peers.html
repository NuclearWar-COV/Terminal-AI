Once a peer has a worker key set (paired), requests can be routed to it. Priority (1-10, higher = more preferred) can be set separately for general chat vs. code-shaped prompts — it biases which machine gets picked when more than one is free. This machine's own role above also matters: a "slave" machine will hand work to a free peer even when it's idle itself, where a "master" only offloads once it's genuinely busier than the peer.
