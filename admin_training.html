Web Scraping — collect training data

Wraps the existing search_engine.py / webscraper.py. Results save into web_training_data/, ready for the Training tab.

Upload training data

Prompt/answer files (.csv, .tsv, .json, .jsonl, .parquet) train the model to actually answer like the examples — one column that looks like a prompt (prompt/question/input/instruction) and one that looks like an answer (answer/response/output/completion), column names matched case-insensitively. Raw text/code files are also accepted and used as a plain text corpus. Files land in web_training_data/admin_uploads/.

Train on collected data

Wraps train.py — trains a LoRA adapter on top of the current base model (base weights stay frozen). Uses whatever's in the data folder below: uploads from above, anything from the Web Scraping tab, and files people have attached in chat.
